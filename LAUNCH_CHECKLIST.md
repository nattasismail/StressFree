# Launch Checklist

## Before publishing
- [ ] Review content and brand name/logo.
- [ ] Test on iPhone, Android and desktop.
- [ ] Test all task controls and timer.
- [ ] Confirm local storage limitation is clearly stated.
- [ ] Add contact email.
- [ ] Review privacy and terms draft.
- [ ] Avoid medical or outcome claims.
- [ ] Ask 5–10 students to test before broad promotion.

## Publishing
- [ ] Create a GitHub account if needed.
- [ ] Create a repository named `stressfree`.
- [ ] Upload `index.html`, `manifest.json` and any assets.
- [ ] Enable GitHub Pages in repository settings.
- [ ] Confirm the public URL works.
- [ ] Test the live version on a phone.

## After publishing
- [ ] Collect feedback via a simple feedback form.
- [ ] Track qualitative feedback and returning users.
- [ ] Improve based on actual evidence.
- [ ] Consider custom domain after early validation.
